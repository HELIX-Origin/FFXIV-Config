# Documentation Directory

Welcome to the **FFXIV Config** documentation. These guides cover installing the config, what each
shipped file controls, how the hotbars and macro menu are organised, and how to fix common issues.

- **[Installation](Installation.md)** — requirements, backing up your character data, and step-by-step installation for one or several characters.
- **[Configuration Files](Configuration-Files.md)** — a reference for each `.DAT` file in [`src`](https://github.com/HELIX-Origin/FFXIV-Config/tree/main/src) and exactly what it controls.
- **[HUD & Hotbars](Hud-And-Hotbars.md)** — the hotbar layout, the job-switching menu and the HUD elements the config positions.
- **[Macros](Macros.md)** — the macro menu and a reference for every macro the config ships.
- **[Troubleshooting](Troubleshooting.md)** — frequently asked questions and fixes.
