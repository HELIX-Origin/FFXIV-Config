# FFXIV-Config

Custom UI built on top of Fr4nsson's FFXIV Config with support for 8.x jobs.

### Features

* **Hotbars 1-3**: Combat hotbars
* **Hotbars 8-9**: Utility hotbars
* **Hotbar 10**: Menu hotbar
* **Command Panel 1**: DoW and DoM jobs.
* **Command Panel 2**: DoH and DoL jobs.
* **Hotbars 4-7**: Free Use Hotbars

### Supported Jobs

* **Tank**: Paladin, Warrior, Dark Knight, Gunbreaker
* **DPS**: Bard, Machinist, Dancer, Black Mage, Summoner, Red Mage, Monk, Dragoon, Ninja, Samurai, Reaper, Viper, Beastmaster, Blue Mage
* **Healer**: White Mage, Scholar, Astrologian, Sage
* **DoH**: Carpenter, Blacksmith, Armorer, Goldsmith, Leatherworker, Weaver, Alchemist, Culinarian
* **DoL**: Miner, Botanist, Fisher

### Installation

1. Click [`here`](https://github.com/HELIX-Origin/FFXIV-Config/archive/refs/heads/main.zip) to download the latest version.
2. Extract the downloaded archive to your preferred location.
3. Copy the contents of the [`src`](src) folder to your FFXIV character configuration directory.
4. Launch FFXIV and verify that the custom UI is applied correctly.
